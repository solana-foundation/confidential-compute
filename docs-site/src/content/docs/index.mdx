## Choose a path

<CardGrid stagger>
	<Card title="Mode A — Stateful" icon="approve-check">
		Register once with `verify_and_register`. Later consumer transactions
		use native Ed25519 and skip P-384. See
		[Mode A](/architecture/mode-a-stateful/).
	</Card>
	<Card title="Mode B — Atomic" icon="list-format">
		One transaction: `verify_atomic_with_nonce` then the consumer instruction.
		Replay defense is a `UsedNonceAccount` PDA. See
		[Mode B](/architecture/mode-b-atomic/).
	</Card>
	<Card title="Integrate" icon="puzzle">
		Three-line Rust helper, Anchor adapters, and the TypeScript builder.
		See [Rust CPI](/integration/rust-cpi/) and the
		[TypeScript SDK](/integration/typescript-sdk/).
	</Card>
	<Card title="Deploy" icon="rocket">
		Run the sidecar inside the enclave. Bind loopback HTTP. Build with Docker.
		See [Sidecar](/deployment/sidecar/).
	</Card>
</CardGrid>
